this weird tool that i made is used to turn your png to .txt files that are used in the console code for rendering textures which makes it simpler to use in console but harder to use in game development because of additional process
usage:
in start.bat after python png2txt there should be 2 additional tags here is an example
python png2txt.py square.png square.txt
this will take square.png and turn it into square.txt (yes it can rename the file in the process)
to make textures i personaly use piskel but any tool can be used
